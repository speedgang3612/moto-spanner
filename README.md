# Moto Spanner MVP

오토바이 주유, 정비, 주행거리, 계기판 사진 기록, 백업/내보내기를 한 화면에서 관리하는 정적 웹앱 MVP입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도 서버나 설치가 필요 없습니다.

## 공개 배포

GitHub Pages 배포 방법은 `GITHUB_PAGES.md`에 정리했습니다.
이후 업데이트는 `scripts/push-to-github.ps1`로 GitHub에 자동 커밋/푸시할 수 있습니다.

## 포함된 기능

- 오토바이 등록: 제조사, 모델명, 연식, cc, 변속 방식, 냉각 방식, 사용 패턴
- 제조사/모델 드롭다운: 주요 제조사와 현행/단종 모델 시드 데이터 포함
- 목록에 없는 제조사/모델 직접 입력 및 재사용
- 모델 선택 시 배기량, 변속 방식, 냉각 방식 자동 입력
- cc/차종/사용 패턴 기반 정비 주기 추천
- 주유 기록 및 평균 연비 계산
- 정비 기록 및 다음 정비 예정 계산
- 정비 완료 기록 기반 다음 교체 주행거리/날짜 계산
- 브라우저 알림 권한을 이용한 정비 필요 알림
- 개인정보/정비 기준/백업/카메라 권한 안내 문구
- 출퇴근/배달/투어링/스포츠 사용 패턴별 교체 주기 보정
- 최근 정비 이력 빠른 입력
- 카메라 직접 촬영 기반 계기판 캡처
- 사용자가 확인한 ODO/TRIP 값 반영 및 즉시 정비 주기 계산
- JSON 백업 및 가져오기
- CSV 내보내기
- 브라우저 로컬 저장소 기반 데이터 저장

## 모델 데이터 메모

`motorcycle-data.js`에는 주요 제조사 21개와 현행/단종 모델 385개를 시드 데이터로 넣었습니다.
전 세계 모든 제조사와 모든 연식별 파생 모델을 완전하게 담은 DB는 별도 수집/검수 작업이 필요합니다.

- NHTSA vPIC 제조사/모델 데이터

- Yamaha Motor 공식 컬렉션 페이지
